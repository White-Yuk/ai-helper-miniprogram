# Proposal

## Why

当前出题链路完全依赖大模型的内部知识，而大模型存在训练数据截止时间。当用户输入超出训练数据的新概念（例如 2026 年才广泛讨论的 "Harness Engineering"）时，模型会把新概念错误关联到其他领域，生成张冠李戴的题目与讲解——学习工具输出错误知识，会直接摧毁用户信任。

这也补齐了产品需求文档的核心愿景缺口（"AI 自动从全网或特定信息源获取知识"）。当前核心闭环（出题 → 闯关 → 报告 → 用户系统）已经完整，正是为出题链路补上"外部知识来源"这一核心拼图的最佳时机。

此外，知识获取 Agent 会显著拉长生成耗时（多轮搜索 + 出题）。经查证：**微信小程序 `wx.request` 的超时上限为 60 秒（硬性上限，超出会被静默截断为 60s）**，同步等待模式在客户端不可行；参考项目亦采用异步任务 + 轮询形态。因此生成流程需同步改造为【异步任务 + 轮询】。

## What Changes

- **异步生成任务（异步任务 + 轮询）**：生成请求改为"创建任务 → 立即返回 → 轮询获取进度与结果"；任务持久化到数据库（服务重启后仍可查询）；保持同步接口兼容（供调试与 H5 场景）。
- **知识获取 Agent**：出题前由 AI Agent 自主决定如何获取知识——多角度联网搜索（basic / deep 两档工具）、用户输入网址时提取网页全文（**提取失败时尝试转关键词搜索补救**）、按"多角度搜索 + 以多数为准"判断术语所属领域；获取内容作为出题依据注入出题 Prompt。
- **过程可见**：
  - **实时进度**：任务状态实时更新细粒度步骤（搜索 → 找到资料 → 深读 → 研判 → 出题），前端轮询渲染，替换现有假动画；
  - **知识溯源**：任务完成时结果携带知识获取轨迹摘要（检索次数、查询词、资料条数），前端展示"知识溯源"卡片。
- **知识盲区守卫**：Agent 未获取到有效内容（失败 / 超时 / 无结果）时，结合模型自评判断"知识盲区"，任务以失败状态结束并携带错误码 4006 与引导，而不是硬编错误题目。
- **降级与兼容**：未配置 API Key 时保持现状行为；Agent 失败自动降级并在无资料时走守卫链；匿名 / 登录两种模式与现有测试不受影响。
- **出题 Prompt v2**：新增【参考资料】区与资料使用规则（依据资料出题、不虚构、防注入）。
- **前端配合**：生成页改为"创建任务 → 轮询"流程（真实步骤流 + 知识溯源卡片 + 盲区提示）；顺带修复现有请求超时设置与小程序端 60s 上限不符的隐患。

## Capabilities

### New Capabilities

- `quiz-search-grounding`: 出题前的智能知识获取（Agent 自主多轮检索、URL 网页提取与失败补救、术语领域判定）、异步生成任务模型（创建 / 轮询 / 持久化）、过程的可见性（实时步骤与知识溯源）、以及失败降级策略。
- `quiz-knowledge-guardrails`: 对"模型知识 + 获取资料"可靠性的判定与降级引导，避免在知识盲区硬编错误题目。

### Modified Capabilities

（无。项目当前没有任何已建立的能力规格，本变更为首次引入 spec。）

## Impact

- **后端代码**
  - 新增：知识获取 Agent 模块（工具构建、Agent 调用、超时护栏、输出与来源提取）、生成任务模块（任务服务 + 后台执行线程池 + 步骤写入）、任务创建 / 查询端点
  - 修改：`quiz_service`（编排：Agent → 守卫 → 出题；支持步骤回调）、`quiz_prompt`（v2）、`config.py`（任务与 Agent 配置项）、数据模型（新增任务模型）
  - 依赖新增：`langchain-tavily`（`langgraph` 已随 langchain 1.x 在环境中，无需新增）
- **API 接口**
  - 新增 `POST /api/v1/quiz/tasks`：创建生成任务（可选登录），立即返回 `task_id`
  - 新增 `GET /api/v1/quiz/tasks/{task_id}`：查询任务状态（状态 / 步骤 / 结果 / 错误）；任务不存在或过期返回 4005
  - `POST /api/v1/quiz/generate`：同步接口保留（兼容 / 调试），行为不变
  - 任务失败时携带错误码（含知识盲区 4006）；任务结果携带 `sources`、`agent_trace`（可选字段）
- **数据库**：新增表 `generation_tasks`（任务状态、步骤、请求快照、结果、错误信息、时间戳）
- **前端**：`pages/generating`（创建任务 → 轮询真实步骤 → 知识溯源卡片 → 盲区提示）；`services/api.ts`（任务接口 + 轮询封装）；`types` 类型更新
- **外部服务**：Tavily Search / Extract API（需注册获取 API Key，免费额度以官网为准）；⚠️ 海外服务的国内连通性风险（失败自动降级，工具层预留替换空间）
- **测试**：新增任务层、Agent 边界、守卫、接口层测试（全部 Mock，离线可跑）；现有 150+ 测试保持全绿
- **明确不做**：报告链路任务化（报告同样受 60s 限制，建议后续独立变更）、用户记忆个性化出题、检索结果落库、多进程任务调度（单进程线程池实现并标注限制）

# quiz-search-grounding Specification

## Purpose

让出题系统在生成题目之前，由 AI Agent 自主联网获取主题的最新知识（多角度搜索或用户指定网页），以异步任务方式执行生成并提供过程可见性，使超出模型训练数据的新概念也能产出可靠的闯关内容。

## Requirements

### Requirement: 异步生成任务
系统 SHALL 以异步任务方式执行题库生成：接收生成请求后立即创建并持久化任务（状态 pending → running → done / failed），SHALL NOT 要求客户端同步等待生成完成；客户端 SHALL 通过轮询任务状态获取进度，在任务终态时获取题目结果或错误信息。任务状态与结果 SHALL 在服务重启后仍可查询。

#### Scenario: 创建任务立即返回
- **WHEN** 用户提交生成请求
- **THEN** 系统立即返回任务标识与初始状态，不等待生成完成

#### Scenario: 轮询获取进度
- **WHEN** 客户端按间隔轮询任务状态
- **THEN** 系统返回当前任务状态与已产生的执行步骤

#### Scenario: 任务完成获取结果
- **WHEN** 任务到达完成状态
- **THEN** 任务结果包含题库数据、（如有）来源信息与知识溯源摘要

#### Scenario: 任务失败获取错误
- **WHEN** 任务到达失败状态
- **THEN** 任务携带错误码与可读信息（如知识盲区 4006），不包含题库数据

#### Scenario: 服务重启后仍可查询
- **WHEN** 服务重启后客户端查询一个已存在的任务
- **THEN** 任务的状态与结果仍可获取

### Requirement: 智能知识获取
当知识获取能力启用且凭据有效时，系统 SHALL 在生成题库前由 AI Agent 自主完成知识获取：执行多角度联网搜索（可多轮、可动态调整搜索参数），并在用户拥有就绪资料库文档时执行资料库检索；获取的内容 SHALL 作为出题参考资料，题目与讲解 SHALL 优先基于这些资料生成。Agent SHALL 依据获取结果的主流方向判断术语所属领域，避免同名歧义导致张冠李戴。

#### Scenario: 歧义术语的领域判定
- **WHEN** 用户提交一个在多个领域有不同含义的术语（如 "Harness Engineering"）
- **THEN** 系统围绕搜索结果的主流含义组织参考资料与题目，而非按字面误配到其他领域

#### Scenario: 常见主题的轻量获取
- **WHEN** 用户提交一个常见主题（如"什么是 HTTP"）
- **THEN** 系统以较少的检索轮次完成知识获取并正常出题

#### Scenario: 复杂主题的深度补充
- **WHEN** 用户提交一个复杂、专业或首轮信息不足的主题
- **THEN** 系统可执行带完整页面内容的深度检索补充资料后再出题

#### Scenario: 资料库与联网的按需组合
- **WHEN** 用户拥有与主题相关的资料库文档，且资料库或联网任一渠道首轮结果不足
- **THEN** Agent 可组合使用资料库命中与联网搜索结果，合并作为出题依据

### Requirement: 资料库检索工具
当登录用户拥有至少一个就绪状态的资料库文档时，系统 SHALL 为出题 Agent 提供「资料库检索」工具；Agent SHALL 自主决定是否检索资料库与是否联网搜索。资料库检索 SHALL 仅覆盖当前用户本人的文档，SHALL NOT 命中其他用户的数据；资料库返回内容 SHALL 视为与其他检索资料同等的出题依据，命中有效片段时 SHALL 计入有效内容判定（不再因缺少联网资料触发知识盲区评估）。

#### Scenario: 有就绪文档时注入工具
- **WHEN** 登录用户拥有至少一个处理完成的资料库文档并请求出题
- **THEN** Agent 工具集中包含资料库检索工具，且可自主选择调用

#### Scenario: 无就绪文档时不注入
- **WHEN** 用户没有就绪的资料库文档（未上传 / 处理中 / 全部失败）
- **THEN** 出题行为与升级前一致（不出现资料库检索相关步骤）

#### Scenario: 用户数据隔离
- **WHEN** 用户 B 出题且用户 A、B 均有资料库文档
- **THEN** 用户 B 的检索与出题依据中不会出现用户 A 的文档内容

#### Scenario: 资料库命中优先
- **WHEN** 用户文档与出题主题高相关
- **THEN** Agent 优先采用资料库命中的内容作为出题依据（而非仅依赖联网或模型知识）

#### Scenario: 命中计入有效内容判定
- **WHEN** 资料库检索命中有效片段（且联网无有效内容）
- **THEN** 系统正常出题并携带来源，不触发知识盲区判定

### Requirement: URL 网页提取
当用户输入包含网址时，系统 SHALL 提取该网页的完整内容作为出题素材；网址与文字混合输入时，系统 SHALL 同时利用网页内容与补充搜索结果。

#### Scenario: 纯 URL 输入
- **WHEN** 用户输入一个网页地址（如文章链接）
- **THEN** 系统提取该页面内容并基于其生成题库

#### Scenario: URL 与文字混合输入
- **WHEN** 用户输入既包含网址又包含描述文字
- **THEN** 系统同时提取网页内容并执行补充搜索，合并作为出题依据

#### Scenario: 提取失败时的检索补救
- **WHEN** 网页内容提取失败（链接失效、反爬等）
- **THEN** 系统尝试以该网页主题进行关键词搜索补救；补救仍无结果时按无资料分支处理

### Requirement: 知识获取过程可见
系统 SHALL 在任务进度中提供细粒度执行步骤（如搜索、深度阅读、网页提取、资料库检索、研判、出题），并在任务完成时的结果中携带知识溯源摘要（检索 / 提取 / 资料库命中次数、查询词、资料条数），供客户端展示。

#### Scenario: 轮询期间获得细粒度步骤
- **WHEN** 客户端在任务运行期间轮询
- **THEN** 返回的步骤列表包含已完成步骤与进行中的步骤

#### Scenario: 完成后获得溯源摘要
- **WHEN** 任务完成
- **THEN** 任务结果中包含本次知识获取的轨迹摘要

#### Scenario: 资料库检索步骤可见
- **WHEN** Agent 在出题过程中调用资料库检索
- **THEN** 步骤流中出现「资料库检索」步骤及其查询词 / 命中条数，溯源摘要包含资料库命中统计

### Requirement: 检索来源可追溯
当题库生成使用了获取的资料时，任务结果 SHALL 携带来源摘要（含来源类型标识：联网 / 资料库），供用户与系统追溯题目的知识出处；来源 SHALL 来自真实的检索 / 提取 / 资料库命中结果。联网来源 SHALL 至少包含标题与链接；资料库来源 SHALL 至少包含文档名称。

#### Scenario: 使用了资料的结果
- **WHEN** 题库基于联网获取的资料生成成功
- **THEN** 任务结果中包含来源条目列表，每条含标题、链接与来源类型（联网）

#### Scenario: 使用了资料库资料的结果
- **WHEN** 题库基于用户资料库命中的文档生成成功
- **THEN** 任务结果中包含资料来源条目（文档名称），来源类型标注为资料库

#### Scenario: 未使用资料的结果
- **WHEN** 出题在无资料的情况下完成（降级或未启用）
- **THEN** 任务结果中不包含来源条目（或来源列表为空）

### Requirement: 检索不可用时的降级
当知识获取完全不可用（未提供联网凭据且用户无就绪资料库文档）时，系统 SHALL 保持与未启用该能力一致的出题行为（纯模型知识出题）。当部分渠道已配置但调用失败（网络异常、超时、限流、额度耗尽或资料库检索异常）时，系统 SHALL 降级为使用仍可用渠道继续出题；全部渠道不可用时降级为无资料出题模式，并继续执行知识可靠性判定；SHALL NOT 因检索 / 资料库问题导致任务失败。

#### Scenario: 未配置检索凭据
- **WHEN** 系统未配置联网凭据且用户没有就绪资料库文档时用户请求生成题库
- **THEN** 出题正常完成，行为与未启用该能力时一致

#### Scenario: Agent 执行超时或异常
- **WHEN** Agent 执行超时或返回错误（网络异常）
- **THEN** 系统降级为无资料模式继续处理（按可靠性判定决定出题或提示盲区），并记录可观测日志

#### Scenario: 检索服务限流或额度耗尽
- **WHEN** 检索服务返回限流或额度耗尽错误
- **THEN** 系统降级为无资料模式继续处理，不因检索问题导致任务失败

#### Scenario: 资料库检索异常降级
- **WHEN** 资料库检索发生异常（向量库不可用等）而联网渠道正常
- **THEN** 系统继续使用联网资料完成出题；若联网也不可用则按无资料模式处理，不因资料库问题导致任务失败

### Requirement: 资料注入约束
注入出题链路的知识摘要 SHALL 受长度上限约束，超出部分 SHALL 被截断，以避免上下文超限与噪声干扰出题质量。

#### Scenario: 知识摘要超长
- **WHEN** Agent 输出的知识摘要长度超过系统配置的上限
- **THEN** 摘要被截断后再参与出题

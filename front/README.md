# 前端 · AI学习助手小程序

基于 **Taro 4 + React 18 + TypeScript**，一套代码同时构建微信小程序与 H5。

- 页面（13 个）：首页 / 生成中 / 闯关答题 / 复盘报告 / 知识掌握 / 学习汇报 / 错题本 / 资料库 / 学习战报海报 等
- 组件：答题面板（单选 / 多选 / 判断 / 填空）、吉祥物、墨线按钮、进度条等「漫画闯关风」组件

```bash
npm install
npm run build:weapp   # 构建微信小程序（产物 dist/，用微信开发者工具导入本目录）
npm run dev:h5        # H5 调试模式（http://localhost:10086）
```

联网调研速览 · 同类产品怎么做的

数据来源：多邻国官方方法论 / 人人都是产品经理拆解 / 优设小程序设计指南
游戏化标杆

多邻国 Duolingo

“让失败感觉安全”：答错时用温和动画 + 鼓励反馈，而不是刺眼的红色警告；角色（猫头鹰）是情感载体，给了用户“玩乐的许可”。

进度设计

多层进度系统

经验值 / 连胜 / 宝石 / 等级 / 排行榜多层并行，无论表现如何，永远有某个维度在推进——这是留存的核心引擎。

国内现状

答题类小程序

卡片化 + 即时反馈 + 金币排行已是标配，但普遍“工具感”重、缺人格化情绪价值——这正是我们差异化的机会。

平台规范

小程序体验基线

一屏一事、点击热区 ≥ 44px、导航极简、加载必有反馈。漫画风要在规范内做夸张，热闹但不能乱。

3

漫画元素 → UI 设计语言映射

原著画风考据：“造型洗练概括、动作夸张、线条干净明快、节奏感强”
🖊️粗黑描边 + 扁平鲜艳色块（美漫技法）
组件语言：所有卡片 / 按钮 = 3px 墨线黑描边 + 4px 硬阴影（无模糊），扁平高饱和色块；按下时向右下位移，像“戳进纸面”
💬黄色对话框（封面招牌元素）
提示系统：AI 讲解、引导文案、鼓励语全部用“带尾巴的对话框气泡”承载，让机器说话像漫画对白
💥爆炸贴纸 / 拟声词（BAM! 轰！叮！）
情绪反馈：答对 = 爆炸星形贴纸 + “叮！答对啦”；连击 = “COMBO ×3”；升级 = “LEVEL UP!”（配 Bangers 漫画体）
📝老师的红笔批改（√ × 大章）
答题批改：对错反馈做成“作业本批改章”——答对盖绿色 √ 章、答错盖红色 × 章 + 手写批注，把挫败感变成校园梗
🦴阿衰胸口的骨头图案（经典记忆点）
彩蛋系统：成就徽章 / 空状态插画 / 加载页里埋“骨头、臭豆腐、蘑菇头”级别的趣味彩蛋（克制、点到为止）
🎭“每一话开头阿衰扮演其他角色”
加载体验：AI 生成时，吉祥物扮演厨师 / 侦探 / 图书管理员…“正在替你翻遍全网找料”，把等待变成笑点
🔴单行本封面：大红底 + 黄字 + 黑描边标题
分享海报：完整复刻封面质感——大红底 + 网点 + 黄色爆炸标题字 + 白色对话框装金句，天生适合朋友圈传播
😂自嘲式幽默台词
文案语气：“噗——答错了，没关系，错题才是升级材料”；“你比 86% 的闯关者答得都快”——接地气、不端着的鼓励
